## ✨ Overview

SchoolPlatform is a modern educational platform designed to simplify school management.

It provides an integrated environment for:

- 👨‍🎓 Students
- 👨‍🏫 Teachers
- 👨‍👩‍👧 Parents
- 🏫 Institutions
- 📚 Subjects
- 📅 Attendance
- 📊 Reports
